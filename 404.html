Hosting & Security

Static-site limitations

Anyone who can access a static GitHub Pages site can download its HTML, CSS, JavaScript, and embedded guidance. The acknowledgment screen and robots file are not access controls.

Data behavior

  • No AI, OpenAI API, Ollama, analytics, or telemetry
  • No application network requests
  • Ticket facts remain in the current tab and are not persisted
  • Only pins, recent template IDs, and display preferences may use local storage

Hosted-build sanitation

Raw DOCX/PDF files, embedded internal screenshots, staff-specific email addresses, payment test data, account/routing numbers, and shared temporary-password wording are excluded or redacted.
