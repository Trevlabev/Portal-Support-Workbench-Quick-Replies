How to use it correctly

Workbench rules

Ivanti remains the official record.

The Workbench is a temporary scratchpad and drafting aid. Copy completed documentation back into Ivanti.

Enter facts once.

Current Ticket passes the issue type, error, and available identifiers into the connected tools.

Review before sending.

Templates, imported profile text, and generated outputs remain editable and require analyst verification.

Use the source hierarchy.

Current manager direction controls when it differs from public or supplemental reference material.

Do not enter unnecessary sensitive data.

Do not place passwords, full payment details, Social Security numbers, or unrelated confidential information in the tool.

What every tab is for

The Work side contains the tools used while handling a live request. The Training side contains learning, practice, reference, and content-governance material. Selecting an Open tab button below switches to the correct workspace automatically.

Deliberately not converted into active training rules

  • Conflicting password requirements
  • Dated outages, release expectations, and implementation schedules
  • Uncertain fees or statements containing “I believe”
  • Incomplete instructions that refer to missing documents
  • County-specific material presented as a statewide rule
  • Legal advice, Clerk procedure, or unverified public guidance

Current confirmation remains required: approval criteria, Cause Codes, county behavior, technical limits, firewall allowlists, financial/refund paths, and items marked Review before use.
