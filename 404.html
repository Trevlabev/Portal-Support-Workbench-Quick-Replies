    About this GitHub Pages build

    This is a static HTML/CSS/JavaScript edition with the desktop workflow efficiencies restored.

    Restored efficiency features

    • Work Mode and Training Mode separation
    • Five-part deterministic Response Builder
    • Two-column Quick Replies selection kit with reorder controls
    • Selected troubleshooting kit
    • Checklist search, state filters, next-incomplete navigation, and completed-group hiding
    • Copy investigation, ticket bundle, checked troubleshooting, and training progress
    • Registration Training, Process Maps, and System Reference
    • Global search, pins, recent items, local ticket parser, and keyboard shortcuts

    Security boundary

    A client-side warning cannot secure a static site. Use an authorized repository and hosting configuration. Raw source documents and internal screenshots remain excluded.

    Data behavior

    • No AI, OpenAI API, Ollama, analytics, or telemetry
    • No network calls made by the application
    • Ticket facts remain only in the current browser tab
    • Pins, recent templates, mode, and display preferences may use browser local storage
