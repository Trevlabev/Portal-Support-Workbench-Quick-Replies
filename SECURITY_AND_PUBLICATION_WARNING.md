# Security and Publication Warning — v3.0

This is a static GitHub Pages package. Anyone who can access the site can download its source files.

Do not place raw internal documents, credentials, passwords, access tokens, full payment-card or bank-account data, Social Security numbers, customer attachments, or unnecessary customer information in the hosted repository.

The Florida Bar workflow performs only deliberate user navigation to official public pages and local parsing of profile text copied by the analyst. It performs no scraping, API calls, automated bulk collection, telemetry, or profile persistence.

Ticket facts remain in memory only and are cleared when the page is refreshed or the ticket is reset.
