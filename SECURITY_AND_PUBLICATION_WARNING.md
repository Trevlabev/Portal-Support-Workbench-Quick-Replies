# Security and Publication Warning

GitHub Pages is static hosting. The browser must download the HTML, JavaScript, CSS, and embedded workflow data to use the application. Therefore, anyone who can reach the site can inspect that content.

## This package does not provide access control

The opening acknowledgment, `robots.txt`, and `noindex` metadata are warnings and indexing preferences only. They do not make a public site private and do not prevent someone with the URL from accessing the content.

## Required review before deployment

Obtain authorization from the appropriate supervisor, repository owner, information-security/IT function, and content owner before publishing.

Review whether the chosen GitHub plan and organization configuration provide the access controls required for internal operational material.

## Data restrictions

Never enter:

- passwords;
- Social Security numbers;
- full payment-card or bank-account numbers;
- CVV/security codes;
- internal credentials or access tokens; or
- unnecessary customer or case information.

The application does not transmit ticket content, but the browser, device, extensions, hosting platform, network, and employer may maintain their own logs or monitoring.
