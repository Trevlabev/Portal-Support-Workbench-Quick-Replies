    About this GitHub Pages build

    This is a static HTML/CSS/JavaScript edition. It uses relative paths and includes an automated GitHub Pages deployment workflow.

    Security boundary

    A client-side warning or password prompt cannot secure a static site. Use an authorized repository and hosting configuration. For genuinely private GitHub Pages access, organizational GitHub Enterprise controls may be required.

    Excluded from this build

    • Raw DOCX and PDF source files
    • Embedded internal-system screenshots
    • Staff-specific email addresses
    • Shared temporary-password text

    Included

    • Nine comprehensive ticket workflows
    • Done / N/A / Open checklist tracking
    • Completion gates
    • Customer, work-note, resolution, and escalation outputs
    • Local ticket-text parser
    • Quick Replies, troubleshooting, source search, and terminology
