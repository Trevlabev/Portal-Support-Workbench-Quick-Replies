# No-Yellow-Callouts Audit — v4.0

The prior v3.9 package did not fully remove the yellow/amber interface treatments. This build corrects that defect.

## Removed or neutralized

- Full-width procedure caution callouts are now plain muted text.
- Procedure, reference, and county review-state badges are neutral gray.
- Reference verification panels use the same neutral treatment as other reference panels.
- County “Confirm before use” sections are neutral.
- System “cannot prove or do” sections are neutral.
- Terminology “Do not confuse” notes are neutral.
- Quick Message review/status labels are neutral.
- Training unanswered/review states no longer use amber/yellow.
- The sentence “Manager-provided baseline sequence. Confirm current browser and firewall guidance before sending.” is absent from the live assets.

## Cache correction

The CSS and JavaScript files were renamed to v4.0-specific filenames so browsers and GitHub Pages do not reuse the older cached assets.
