# v4.3 — Restored No-AI Popup and Procedure Checklists

## Corrections

- The simple “No AI is used in this tool” dialog now appears on every new page load.
- The old `noAiSeen` browser preference is ignored and removed from future preference saves.
- Job Procedure steps are interactive checklists again.
- Each procedure shows a live checked-step count and a Clear checks control.
- Checked steps remain selected while navigating and filtering during the current browser session.
- Procedure checklist state is not written to local storage.
- Checked procedure steps can be added to the Current Ticket work note.

## Privacy behavior

The application continues to save only non-sensitive preferences and training progress. Ticket facts, drafts, imported Florida Bar details, and procedure checklist state are session-only.
