# v4.5 Home Dashboard

## Purpose

The Workbench now opens to a dedicated Home dashboard instead of placing a new analyst directly into Current Ticket. The dashboard explains the intended workflow and provides direct access to each daily tool.

## Dashboard contents

- Current Ticket status and remaining required items
- Start New Ticket, Open Current Ticket, and Open Training actions
- Three-step daily workflow: capture facts, use the relevant tool, finish documentation
- Direct access to Messages, Troubleshooting, Florida Bar Search, Known Issues, Job Procedures, and Training
- Workbench operating rules, privacy reminder, and keyboard shortcuts

## Navigation behavior

- Home is the first Daily Work navigation item and the default page on each load.
- Work mode returns to Home.
- New Ticket opens a cleared Current Ticket workspace.
- Training actions switch to Training mode and open the selected training page.
- Current Ticket remains at the bottom of the Daily Work sidebar.

## Data handling

The dashboard does not persist or transmit ticket information. Its Current Ticket status is derived only from the in-memory ticket state for the current browser session.
