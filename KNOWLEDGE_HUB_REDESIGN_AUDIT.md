# v3.8 Knowledge Hub Redesign Audit

## Scope

The following five Training & Reference areas were rebuilt:

- Job Procedures
- System Reference
- Terminology
- Reference Library
- County Notes

The redesign uses the manager-provided source material already classified in the v3.5 content audit and the nine Current Ticket workflows. It does not treat public or general information as a replacement for the supplied procedures.

## Results

| Area | Before | v3.8 |
|---|---:|---:|
| Job Procedures | 9 workflow lists + 4 raw source blocks | 13 structured procedure guides |
| System Reference | 8 two-paragraph cards | 9 evidence-source guides + 8-question matrix |
| Terminology | 29 one-sentence definitions | 50 operational term guides |
| Reference Library | 15 raw source-text disclosures | 15 structured reference articles |
| County Notes | 8 separate raw notes | 5 consolidated county guides |

## Material corrections

1. Filing-status codes were removed from the Master Ticket procedure and placed in a dedicated reference article.
2. Court Monitor and Third-Party Vendor routing now state exactly what the source supports and identify what still needs current confirmation.
3. System Reference now starts with the question being answered and explicitly states what each source cannot prove.
4. Terminology now includes why each term matters and the most common confusion to avoid.
5. Duplicate Broward and Miami-Dade notes were consolidated by county.
6. The Miami-Dade source sentence advising the analyst to choose an unrelated party to get a filing through was not carried forward as active guidance. The county guide explicitly identifies that as an unsafe bypass instruction.
7. Changeable technical limits, incomplete source notes, account-ownership rules, and county behavior remain labeled for current confirmation.

## Source preservation

The original manager-source text remains available in Content Audit. v3.8 adds structured active guidance without altering the preserved source record.
