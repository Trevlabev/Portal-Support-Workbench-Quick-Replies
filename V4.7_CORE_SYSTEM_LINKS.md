# Portal Support Workbench v4.7 — Core System Quick Links

## Home dashboard

The Home dashboard now includes three credential-safe launch cards:

| System | Official address | Account guidance |
|---|---|---|
| Ivanti / HEAT | `https://www.myhelpsupport.com/HEAT` | Use the approved Ivanti / HEAT credentials. |
| RAC — System Admin | `https://www.myflcourtaccess.com/` | Username is the analyst's `flclerks` username. Use the separate RAC-specific password, not the normal login password. |
| Attorney E-Filing Portal | `https://www.myflcourtaccess.com/` | Username is `[flclerks username]Atty`. Use the separate password assigned to the Attorney account. |

RAC and the Attorney E-Filing Portal intentionally open the same website but use different accounts.

## Sidebar

Home remains the first tab under Daily Work in the left sidebar.

## Job Procedures

A new interactive procedure, **Sign in to Ivanti, RAC, and the Attorney E-Filing Portal**, includes:

- When each account should be used
- Required systems
- Preparation and credential-handling rules
- Nine checkbox steps
- What to document in Ivanti
- Completion criteria
- Related workflows and tools

## Credential handling

The Workbench displays account-selection guidance but stores no passwords, temporary passwords, authentication codes, or access tokens. Passwords are entered only on the official login page.
