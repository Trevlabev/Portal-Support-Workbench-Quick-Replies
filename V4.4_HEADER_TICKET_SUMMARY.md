# v4.4 — Header Ticket Summary

The Current Ticket utility was moved out of the bottom-right corner and into the sticky application header.

## Changes

- Removed the floating drawer and minimized thumbnail from the page body.
- Converted the existing header ticket chips into a single expandable Current Ticket control.
- Added an anchored summary panel containing workflow, customer, filing number, remaining items, ticket navigation, work-note entry, and summary copying.
- Added outside-click and Escape-key dismissal.
- Hid the ticket summary in Training mode.
- Added a compact responsive header treatment for narrower screens.

## Privacy

The change is presentational only. Ticket facts remain session-only and are not written to local storage.
